About

Reliable apps, readable code

I'm a Computer Science undergraduate who spends most evenings inside Android Studio. My rule of thumb: if a screen needs a comment to explain what it does, it needs a refactor.

How I build

MVVM and clean layering, unidirectional data flow, and state modelled as explicit sealed classes. Coroutines and Flow for anything that touches I/O, so the UI never stutters.

What I care about

Offline-first behaviour, graceful error states, and screens that load instantly from cache. A feature isn't done until it survives airplane mode and a flaky network.

Currently exploring

Kotlin Multiplatform, Compose performance profiling, and shipping apps through a proper CI/CD pipeline — which is exactly where the Docker and nginx side of this project comes in.
